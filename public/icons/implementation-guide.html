Favicon Implementation Guide

1. Upload Files

Upload all PNG files to your website's root directory (same level as index.html).

2. Add to HTML Head

Add these lines to the <head> section of your HTML:

<!-- Modern SVG favicon (preferred) -->
<link rel="icon" type="image/svg+xml" href="/favicon.svg">

<!-- Classic ICO favicon (broad compatibility) -->
<link rel="icon" type="image/x-icon" href="/favicon.ico">

<!-- Fallback PNG favicons -->
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">

<!-- Apple Touch Icons -->
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="apple-touch-icon" sizes="152x152" href="/apple-touch-icon-152x152.png">
<link rel="apple-touch-icon" sizes="144x144" href="/apple-touch-icon-144x144.png">
<link rel="apple-touch-icon" sizes="120x120" href="/apple-touch-icon-120x120.png">

<!-- Android Chrome -->
<link rel="icon" type="image/png" sizes="192x192" href="/android-chrome-192x192.png">

<!-- Theme color (matches the manifest) -->
<meta name="theme-color" content="#ffffff">

<!-- Web App Manifest -->
<link rel="manifest" href="/manifest.json">

Maskable and monochrome icons are not referenced with <link> tags — they are declared in manifest.json only.

3. For PWA Support

The included manifest.json enables Progressive Web App features and already declares every icon purpose Android needs. Customize the app name, start_url, scope and colors as needed.

{
  "id": "/",
  "name": "A",
  "short_name": "A",
  "start_url": "/",
  "scope": "/",
  "display": "standalone",
  "theme_color": "#ffffff",
  "background_color": "#ffffff",
  "icons": [
    { "src": "/android-chrome-192x192.png", "sizes": "192x192", "type": "image/png", "purpose": "any" },
    { "src": "/android-chrome-512x512.png", "sizes": "512x512", "type": "image/png", "purpose": "any" },
    { "src": "/icon-192-maskable.png", "sizes": "192x192", "type": "image/png", "purpose": "maskable" },
    { "src": "/icon-512-maskable.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" },
    { "src": "/icon-monochrome-432.png", "sizes": "432x432", "type": "image/png", "purpose": "monochrome" }
  ]
}
  • purpose: "any" - the plain icon, shown as-is by browsers and desktop installs.
  • purpose: "maskable" - full-bleed icon for Android adaptive icons. The artwork sits inside the safe zone (the centre 80% circle) so it is never clipped by the launcher mask.
  • purpose: "monochrome" - white silhouette on transparency, used by Android 13+ themed (dynamic color) icons. Android tints it with the user's wallpaper palette.

Keep the purposes in separate entries. Combining them ("purpose": "any maskable") makes the padded icon appear in places that do not mask it.

4. File List

  • favicon.svg - Modern SVG favicon (scalable, preferred)
  • favicon.ico - Classic ICO favicon (maximum compatibility)
  • favicon-16x16.png - 16×16 favicon (fallback)
  • favicon-32x32.png - 32×32 favicon (fallback)
  • favicon-48x48.png - 48×48 favicon
  • favicon-96x96.png - 96×96 favicon
  • apple-touch-icon.png - 180×180 Apple touch icon
  • apple-touch-icon-152x152.png - 152×152 Apple touch icon
  • apple-touch-icon-144x144.png - 144×144 Apple touch icon
  • apple-touch-icon-120x120.png - 120×120 Apple touch icon
  • android-chrome-192x192.png - 192×192 Android Chrome icon
  • android-chrome-512x512.png - 512×512 Android Chrome icon
  • icon-192-maskable.png - 192×192 maskable icon (safe-zone padded, full-bleed background)
  • icon-512-maskable.png - 512×512 maskable icon (safe-zone padded, full-bleed background)
  • icon-monochrome-432.png - 432×432 monochrome icon for Android 13+ themed icons
  • manifest.json - PWA manifest file
  • implementation-guide.html - this guide

5. SVG Favicon Benefits

The SVG favicon (favicon.svg) is the modern standard and offers several advantages:

  • Scalable - Looks crisp at any size
  • Smaller file size - Often smaller than multiple PNG files
  • Future-proof - Supported by all modern browsers
  • Dark mode support - Can include CSS for automatic dark/light theme switching
